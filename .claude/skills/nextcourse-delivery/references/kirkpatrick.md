# 柯氏四级评估 — 指标写法与题库

> `nextcourse-delivery` Phase 6 的参考。**默认只设计 L1 + L2**，L3/L4 问过用户再展开。

## 一句话区分四级

| 级 | 问的问题 | 什么时候收 | 成本 |
|---|---|---|---|
| L1 反应 | 学员觉得有用吗？ | 结营当场 | 低 |
| L2 学习 | 学员真的会了吗？ | 结营考核 | 中 |
| L3 行为 | 回去真的做了吗？ | 训后 30–90 天 | 高，要业务方配合 |
| L4 结果 | 业务指标动了吗？ | 训后 3–6 个月 | 最高，要基线与口径 |

**L1 高不代表 L2 达标**——「今天很有收获」和「他能独立做出来」是两件事。
只交 L1 的评估报告没有说服力，L1+L2 是可交付的最低组合。

## L1 · 反应问卷

### 题目设计原则

- **题目要能指导改课**。「您对本次培训是否满意」拿到 4.6 分你也不知道该改什么；
  「练习环节让我真的动了手」拿到 3.1 分你就知道下次要加动手时间。
- 6 道封闭题 + 3 道开放题，1–5 分制，2 分钟内能填完。超过这个长度回收率掉一半。
- **不要问「讲师亲和力」这类无法改进的项**，除非你真打算换讲师。

### 可直接用的题库（按需挑 6 道）

| 维度 | 题目 |
|---|---|
| 相关性 | 课程内容与我的实际工作直接相关 |
| 清晰度 | 讲师把内容讲清楚了，我能跟上 |
| 参与度 | 练习环节让我真的动了手，不只是听 |
| 可用性 | 我拿到的产出物回工位能直接用 |
| 节奏 | 课程时长与节奏安排合理 |
| 净推荐 | 我愿意把这门课推荐给同事 |
| 难度 | 内容难度对我合适（太简单 / 太难都扣分，需反向计分） |
| 材料 | 学员手册与练习数据包好用 |

### 开放题（固定这三道）

1. 今天最有用的一件事是什么？
2. 哪个环节应该砍掉或缩短？
3. 你希望补充什么内容？

第 2 题最有价值也最容易被省略——**主动问"哪里该砍"，学员才会说真话**。

### 目标值参考

综合均分 ≥ 4.5 / 5，净推荐题 ≥ 4.3，任一单项 < 3.8 即列入下一版必改项。

## L2 · 学习考核

### 考核任务从哪来

**直接取自每条 outcome 的 `evidence` 字段**，不要另设考题。
`evidence` 是设计阶段就说好的判定证据，另起炉灶等于把逆向设计推翻重来。

| outcome 的 bloom | 考核形式 |
|---|---|
| remember / understand | 口述互讲、判断题、概念辨析（占比不要超过 30%） |
| apply | **实操任务**：给定输入 → 学员产出成品 → 对照检查清单 |
| analyze | 情景判断：给 3 个场景，说出选择与理由 |
| evaluate | 点评练习：给一份有问题的样例，指出问题并给改法 |
| create | 结营作品：作战包 / 方案 / 模板，按量规打分 |

### 量规怎么写才不是废纸

每条 outcome 一个维度，四级，**每一级都写成可观察的行为**：

| 等级 | 写法要求 | 反面例子 |
|---|---|---|
| 优秀 | 比达标线**多做到什么**，具体到动作 | ~~完成质量很好~~ |
| 达标 | 直接用 outcome 的 `success` 字段 | ~~基本掌握~~ |
| 待改进 | 产出物完成但**缺哪个关键要素** | ~~有待提高~~ |
| 未达标 | 未提交，或与任务要求不符 | ~~不认真~~ |

打分规则：
- 各维度独立打分，**不做加权平均**——平均分会掩盖某一项完全没学会；
- 只看交上来的产出物，不看课堂表现印象；
- 全部维度达标项 ≥ 80% 记为通过，未通过者结营后 2 周内补交。

## L3 / L4 · 只在拿到基线承诺后才做

### 开启前必须落实的三件事

1. **基线数据由谁提供** —— 写下姓名 + 部门，不写「业务部门」这种没人认领的说法；
2. **口径是什么** —— 指标定义、统计周期、剔除规则（离职 / 转岗 / 异常单据怎么处理）；
3. **追踪节奏** —— 30 / 60 / 90 天谁来收、用什么表、回收率多少算有效。

三件事没落实就写进去的 L3/L4 指标，全是空指标。
**需要基线才能定值的目标值一律标 `*`**（例：`续保率提升 5pt*`），
`nextcourse check` 会检查 L3/L4 指标是否指定了基线责任人。

### L3 行为 · 低成本做法

不做完整追踪也能拿到行为证据：**第 30 天发一次学员的行动承诺书复盘表**
（`package/4_action-plan.md` 里那张 30/60/90 表）。回收率通常 40–60%，
足够写进结项报告，成本几乎为零。

正式做法：直属主管观察量表（3–5 条行为，训前训后各评一次）+ 系统留痕数据。

### L4 结果 · 指标选择

只选**课程能直接影响**的指标，且提前声明归因边界：

| 好指标 | 坏指标 |
|---|---|
| 目标动作的完成率、耗时、返工率 | 总营收（受太多因素影响，归不到课程头上） |
| 单位产出质量得分 | 员工满意度（那是 L1 的活） |

报告里必须写一句：「本指标同时受 X / Y 影响，培训不是唯一变量。」
**主动声明归因边界，比夸大效果更能建立信任。**
