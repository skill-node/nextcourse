# 互动手法库 — 按题材域 × 班级规模选型

> `/course-delivery` Phase 5 的参考。目标是把「小组共创」这种词，
> 变成讲师照着念就能带起来的活动指令。

## 选型表

| 题材域 | 主推手法 | 慎用 |
|---|---|---|
| 领导力 / 软技能 | 情境卡片研讨、角色扮演 + 观察员、自评量表 + 同伴反馈 | 动手操作类任务（没东西可操作，会尴尬） |
| AI / 技术工具 | 跟做演示、故障排查挑战、before/after 改写 | 纯讨论（学员想要的是「我也能做出来」） |
| HR / 制度合规 | 判断题擂台、灰色地带辩论、真实案例复盘 | 记忆型抢答（考条文背诵毫无迁移价值） |
| 数据 / 分析 | 读图找错、指标口径辩论、同一数据两种结论 | 大段公式推导 |
| 销售 / 客户经营 | 话术对练、异议处理轮转、客户画像共创 | 讲师单向示范（一定要让学员开口） |
| 创意 / 设计 | 快速迭代（3 轮 × 5 分钟）、盲评投票 | 一次成稿的大作业 |

## 班级规模决定形态

| 规模 | 可行形态 | 不可行 |
|---|---|---|
| ≤ 12 人 | 全员轮流发言、单人实操 + 讲师逐个点评 | 分组竞赛（组太少没气氛） |
| 13–30 人 | **4–5 人小组是最佳单元**，组内共创 + 组间互评 | 全员逐个发言（时间不够） |
| 31–60 人 | 小组 + 抽样分享（每轮只抽 2–3 组）、举手投票 | 逐组点评、人人动手且要求当场检查 |
| > 60 人 | 结对讨论（turn-to-your-neighbor）、现场投票、示范 + 集体跟做 | 任何需要讲师逐一验收的活动 |

**人均发言机会 ≥ 1 次**是硬指标。算法：可用互动时间 ÷ 人数 ≥ 60 秒，达不到就改小组形态。

## 手法卡（照着填就能用）

每个活动写清五件事，缺一件现场就会乱：

```
活动名  ：一句话说清学员要做什么
分组    ：几人一组 / 是否需要角色分工
时间盒  ：X 分钟（分解到"读材料 2 分 + 讨论 5 分 + 汇报 3 分"）
交付物  ：结束时每组交出什么（写在纸上 / 填在手册第 X 页）
评分点  ：讲师点评时只看哪 2–3 点（对应 rubric 的维度）
```

### 时间盒经验值

| 活动 | 时间 | 备注 |
|---|---|---|
| 结对讨论 | 3–5 min | 破冰与唤醒，不产出物 |
| 小组讨论出结论 | 8–12 min | 少于 8 分钟只能得到表层答案 |
| 个人实操（有模板） | 15–20 min | 无模板要 ×1.5 |
| 小组共创产出物 | 25–40 min | 必须给中途检查点（做到一半讲师巡场） |
| 组间互评 | 每组 3 min | 超过 6 组就抽样，别让所有人听完 |
| 汇报分享 | 每组 2–3 min | 讲师必须计时，否则第一组会讲 8 分钟 |

**留 10% 缓冲**。一天课排满 100% 的结果一定是最后一个模块被压缩，
而最后一个模块通常是最重要的实操。

## 认知负荷节奏（硬规则）

- **每 90 分钟必须切换形态**：讲授 → 动手 → 讨论 → 互评；
- **午后第一段绝不安排纯讲授**（血糖低谷，讲什么都进不去），排动手或走动型活动；
- 每个模块**至少一次**人均发言机会 ≥ 1 次的互动；
- **产出物当场交**，不留到课后——课后交付率通常低于 20%。

## 游戏化积分（可选，别做复杂）

| 行为 | 积分 |
|---|---|
| 小组按时提交产出物 | +2 |
| 被选为示范案例 | +3 |
| 给别组提出被采纳的改进意见 | +2 |
| 主动分享自己的失败案例 | +1 |

两条纪律：
1. **积分只用于结营即时兑现**（小奖品 / 优先选题），不进任何考核记录，
   一旦和考核挂钩，学员就开始表演而不是学习；
2. 规则不超过 5 条，写在白板上全程可见。

## 常见翻车与对策

| 现象 | 真正的原因 | 对策 |
|---|---|---|
| 小组讨论冷场 | 问题太大或太抽象 | 换成「从这 3 个选一个并说理由」 |
| 永远是同一个人在说 | 没给角色 | 指定组长 / 记录员 / 汇报人，每轮轮换 |
| 汇报环节严重超时 | 没有计时与顺序 | 计时器可见 + 抽样汇报 + 先说结论的模板 |
| 学员低头玩手机 | 上一段讲授超过 20 分钟 | 插入 3 分钟结对讨论重新唤醒 |
| 产出物质量参差 | 没给样例 | 先展示一份「达标长什么样」再放手 |
| 老手觉得太浅 | 起点设错 | 给老手加「挑战版任务」或请他当组内教练 |
