Module 1：认知重塑

  • 组件: .module-cover .module-1
  • 说明: 建立“人机协同”的正确心智，明确AI的能与不能。

你是否也曾依赖“直觉”管理？

  • 盲区：个人经验有限，难以全面评估。
  • 偏见：易受近因效应、光环效应影响。
  • 低效：陷入重复的信息处理，缺乏深度思考时间。
  • 组件: .card

定位你的“AI副驾驶”

  • 组件: .grid-2
  • 左侧（它能做）：
  • 无偏见处理海量数据
  • 识别隐藏模式与风险
  • 提供预测与备选方案
  • 生成报告与沟通草稿
  • 右侧（它不能做）：
  • 替代人类情感与信任
  • 进行价值观与伦理判断
  • 承担决策的最终责任
  • 执行并建立人际关系

Module 2：工具武装

  • 组件: .module-cover .module-2
  • 说明: 选择你的工具，并学会如何高效地向AI“提问”。

你的AI工具箱：按需选择

  • 组件: .grid-3
  • 通用对话型
  • 办公嵌入型
  • 垂直分析型
  • 建议：从 “1个通用型 + 1个办公型” 开始。

精准提问的艺术：四要素指令法

  • 角色：指定AI身份（如“领导力教练”）。
  • 任务：清晰说明要做什么。
  • 格式：明确输出形式（如“表���”、“清单”）。
  • 要求：提出具体限制（如“可操作”、“积极语气”）。
  • 组件: .icon-card-grid
  • .icon-card: 角色
  • .icon-card: 任务
  • .icon-card: 格式
  • .icon-card: 要求

好指令 vs 差指令

  • 组件: .grid-2 .vs-bad .vs-good
  • 左侧（差指令）：
  • “帮我分析一下团队。”
  • “写一份反馈。”
  • 结果：空泛、无用。
  • 右侧（好指令）：
  • “角色：组织发展专家。任务：分析团队在‘创新’与‘执行’上的强弱项…格式：先结论后分点…要求：基于数据，具体可操作。”
  • 结果：结构化、有洞察。

将观察转化为AI可用的“燃料”

  • 数据类型：
  • 定量数据（项目完成率）
  • 定性文本（周报、反馈）
  • 行为记录（协作活跃度）
  • 记录习惯：会后三句话记录关键观察。
  • 脱敏原则：输入前移除敏感信息（用“员工A”、“项目X”）。
