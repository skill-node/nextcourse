# 你是否也曾依赖“直觉”管理？
## 直觉管理的三大挑战
- **盲区**：个人经验有限，难以全面评估。
- **偏见**：易受近因效应、光环效应影响。
- **低效**：陷入重复的信息处理，缺乏深度思考时间。

# 定位你的“AI副驾驶”
## 它能做 vs. 它不能做
- 组件: .grid-2
- **左侧（它能做）**：

# 精准提问的艺术：四要素指令法
## 垃圾输入，垃圾输出
- **角色**：指定AI身份（如“领导力教练”）。
- **任务**：清晰说明要做什么。
- **格式**：明确输出形式（如“表���”、“清单”）。
- **要求**：提出具体限制（如“可操作”、“积极语气”）。
- 组件: .icon-card-grid
    - .icon-card: 角色
    - .icon-card: 任务
    - .icon-card: 格式

[Slide 10]
# 好指令 vs 差指令
## 对比演示
- 组件: .grid-2 .vs-bad .vs-good
- **左侧（差指令）**：
    - “帮我分析一下团队。”
    - “写一份反馈。”
    - **结果**：空泛、无用。
- **右侧（好指令）**：
    - “角色：组织发展专家。任务：分析团队在‘创新’与‘执行’上的强弱项…格式：先结论后分点…要求：基于数据，具体可操作。”
    - **结果**：结构化、有洞察。

# 将观察转化为AI可用的“燃料”
## 管理数据的类型与准备
- **数据类型**：
    - 定量数据（项目完成率）
    - 定性文本（周报、反馈）
    - 行为记录（协作活跃度）
- **记录习惯**：会后三句话记录关键观察。
- **脱敏原则**：输入前移除敏感信息（用“员工A”、“项目X”）。

[Slide 13]
# 场景一：智能识人
## 绘制团队能力图谱
- **核心方法**：
    1.  整合碎片信息，生成**结构化画像**。
    2.  从 **“硬技能-软技能”**、**“潜力-绩效”** 等维度分析。
    3.  发现**高潜力员工**与**团队能力短板**。
- **输出示例**：团队能力雷达图或九宫格。
- 组件: .layout-img-right

[Slide 14]
# 场景二：精准反馈
## 定制个性化沟通方案
- **核心方法**：
    1.  基于员工特点（专家/新人、成就型/关系型），生成**定制话术**。
    2.  AI提供**沟通脚本**、**问题清单**、**邮件草稿**。
    3.  **关键**：内化AI输出，用真诚的语言表达。
- **对比示例**：对同一员工，“批评指正”与“委派挑战”两套不同话术要点。
- 组件: .grid-2

[Slide 15]
# 场景三：审慎决策
## 优化策略与模拟推演
- **核心方法**：
    1.  将AI作为 **“决策模拟器”**，预测不同方案的结果。
    2.  生成**选项利弊清单**，从多维度评估。
    3.  提供不受团队影响的 **“第三方视角”**，发现盲点。
- **应用示例**：“推行项目制变革，AI推演可能遇到的阻力及应对沟通要点。”

# 权力越大，责任越大
## 警惕AI应用三大陷阱
- 组件: .grid-3
- **偏见放大**
    AI可能复制并放大数据中的社会偏见。
- **隐私安全**

- **伦理四问**
    是否透明、公平、可问责、尊重人的尊严？
