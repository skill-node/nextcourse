01

语义色Semantic colors

这六个是有语义的：学员在一份 deck 里反复看到 --danger 就是"别这么干"。 同一个色不能既表示"危险"又表示"第 5 模块"。
色块下方那一档是 R5：这五个语义色在 .text-* / .vs-* h3 / 统计数字 / 图标卡里都是当文字色用的， 落在 --bg-slide 上必须 ≥4.5:1，否则那些规则等于白写。These six carry meaning: seeing --danger over and over across a deck is what teaches the audience "don't do this". One color cannot mean both "danger" and "module 5".
The row under each chip is R5: all five semantic colors are used as text colors in .text-* / .vs-* h3 / stat numbers / icon cards, so on --bg-slide they must reach ≥4.5:1 — otherwise those rules are dead letters.

--primary … 标题、强调、数字、边框Headings, emphasis, numbers, borders
--primary-dark … 封面标题、深色背景Cover titles, dark backgrounds
--secondary … 示例、tip、时间轴结束端Examples, tips, timeline end
--accent … 警示、callout、次级强调Warnings, callouts, secondary emphasis
--success … check-list、vs-good、正面结果check-list, vs-good, positive outcomes
--danger … vs-bad、错误、反面例子vs-bad, errors, counter-examples

十个模块封面（--module-1 … --module-10）Ten module dividers (--module-1 … --module-10)

多数课程只用到前 3–5 个，所以越靠前的位置越要安全。 每张下面标出实测色值、标题实际取到的文字色、对比度，以及和语义色/其他模块的撞车情况。 module-1 = --primary 这类是各配色的惯例，只标灰不报警；撞上 --danger / --accent / --success 才算真冲突。Most courses only reach modules 3–5, so the earlier the slot, the safer it has to be. Each card reports the measured color, the text color the title actually resolves to, the contrast ratio, and any collision with a semantic color or another module. module-1 = --primary is a convention across schemes — noted in grey, not flagged; only collisions with --danger / --accent / --success count as real conflicts.

把 AI 从参谋变成助理

大模型是发动机，智能体是整车。你在聊天框里问它"这份合同有什么风险"，它给你一段分析； 你在智能体里给同样的指令，它会把二十份合同逐条读完，把风险点整理成一张表， 然后把表存到你指定的目录里。1234567890 —— 数字与中文混排的字重表现看这一行。

A large model is the engine; an agent is the whole vehicle. Ask a chat box "what are the risks in this contract" and you get a paragraph back; give an agent the same instruction and it reads all twenty contracts, tabulates every risk and files the table where you told it to. 1234567890.

卡片四态Four card variants

标准卡片Standard card

正文用 --text-body，标题用 --primary。这是 deck 里出现频率最高的容器。Body takes --text-body, heading takes --primary. The most common container in a deck.

主色卡片Primary card

底色 --primary，文字必须显式配对，不能靠继承。Filled with --primary; the text color must be paired explicitly, never inherited.

辅助色卡片Secondary card

底色 --secondary，用于示例、tip。Filled with --secondary, for examples and tips.

强调色卡片Accent card

底色 --accent，用于警示与次级强调。Filled with --accent, for warnings and secondary emphasis.

概念定义卡Concept card

办公智能体 (Agent)Office agent (Agent)

能调用工具、能读写文件、能把一串动作跑完的 AI —— 区别于只能在对话框里出主意的聊天 AI。An AI that calls tools, reads and writes files, and runs a chain of actions to completion — as opposed to a chat AI that only offers advice in a text box.

示例：Example: 聊天 AI 告诉你发票该怎么整理；智能体直接把二十张发票整理成一张明细表。A chat AI tells you how to organize your invoices; an agent turns twenty of them into one itemized sheet.
